# 界面关闭时清理订阅

背包窗口打开时监听物品变化，关闭后就应该停止监听。否则即使界面已经隐藏，回调仍可能执行；如果监听的是长期存在的全局总线，回调还会一直持有界面引用。

Lifetime 是一个“我负责释放的资源清单”。它不寻找资源、不创建总线，也不决定界面什么时候关闭。你把 Subscribe 返回的句柄登记进去，退出时统一释放。

| 动作 | 写法 | 作用 |
| --- | --- | --- |
| 本次打开开始监听 | `var subscriptions = new Lifetime();` | 建立本次启用周期的清理集合 |
| 登记监听句柄 | `subscriptions.Add(events.Subscribe<...>(...));` | 以后关闭集合时自动退订 |
| 本次界面关闭 | `subscriptions.Dispose();` | 逆序释放所登记资源，重复释放安全 |

总线由关卡或游戏入口拥有，因此不要把借用的总线加入界面的 Lifetime。

## 可启停组件的完整写法

下面是使用方式示例，不是模块额外提供的组件。`HealthChanged` 使用 [[Guides/Events/角色事件通知]] 中定义的业务事件。把脚本命名为 HealthBarEvents.cs，挂在血条对象；Inspector 的 Character Id 对应目标角色。这里用只读属性接收血量，你的 UI 绘制代码再读取它们。

```csharp
using System;
using GameSysLab.Core.Events;
using GameSysLab.Core.Lifecycle;
using UnityEngine;

public sealed class HealthBarEvents : MonoBehaviour
{
    [SerializeField] private int characterId = 1;
    private EventBus events;
    private Lifetime subscriptions;
    public int CurrentHealth { get; private set; }
    public int MaxHealth { get; private set; }

    // 由关卡启动代码传入同一条事件总线。
    public void BindEvents(EventBus levelEvents)
    {
        if (events != null)
            throw new InvalidOperationException("此血条已经绑定事件总线。");
        events = levelEvents ?? throw new ArgumentNullException(nameof(levelEvents));
        if (isActiveAndEnabled) SubscribeToHealth();
    }

    private void OnEnable()
    {
        if (events != null) SubscribeToHealth();
    }

    private void SubscribeToHealth()
    {
        if (subscriptions != null) return;
        var current = new Lifetime();
        try
        {
            current.Add(events.Subscribe<HealthChanged>(OnHealthChanged));
            subscriptions = current;
        }
        catch
        {
            current.Dispose();
            throw;
        }
    }

    private void OnHealthChanged(HealthChanged change)
    {
        if (change.CharacterId != characterId) return;
        CurrentHealth = change.CurrentHealth;
        MaxHealth = change.MaxHealth;
    }

    private void OnDisable()
    {
        var previous = subscriptions;
        subscriptions = null;
        previous?.Dispose();
    }

    private void OnDestroy()
    {
        OnDisable();
        events = null;
    }
}
```

这是“绑定一次，允许反复启停”的组件。如果角色或总线换了，创建新的血条组件；不要重新启用仍绑定已关闭旧总线的组件。首次显示的血量应从角色当前状态读取，本例只展示后续事件接收。

## 释放时需要知道的几件事

每次打开建立新的 Lifetime；已关闭的集合不能重开，继续 Add 会立即释放新资源。同一对象实例重复登记只释放一次。某个资源释放失败不会阻止其他清理，最后统一抛 AggregateException；调用方应记录异常。

所有操作在创建集合的线程执行，Unity 组件中就是主线程。Lifetime 不会自动 Destroy GameObject、卸载场景或等待后台任务。它只会调用已登记对象自己的 Dispose，因此后台任务需要自己实现取消与完成观察。

成员和详细参数见 [[Reference/Lifecycle/Lifetime]]。
