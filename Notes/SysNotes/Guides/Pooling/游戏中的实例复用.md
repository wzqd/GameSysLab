# 游戏中的实例复用

角色生成弹丸时，从拥有该类弹丸的池借出；设置位置和业务数据后激活；命中或退出时释放自己的租约。不要保存已归还的实例继续使用。

## Unity 安装与调参

在关卡拥有者对象挂 GameObjectPoolHost，Prefab 拖入固定资源，Max Inactive 默认 32（空闲对象数量，允许 0）。进入关卡由装配入口 Initialize(reset)；配置在初始化时固定。普通 ObjectPool 和 PoolLease 不挂载。

以下为装配入口中的调用片段，host 已由序列化引用传入，activeRoot 为活动父节点：

```csharp
host.Initialize();
var lease = host.Rent();
lease.Value.transform.SetParent(activeRoot, false);
// 在此设置位置、伤害等本次数据，然后激活。
lease.Value.SetActive(true);
// 命中或离开时：
lease.Dispose();
```

重置回调由业务提供，清空上一次状态；调用前实例已经禁用。归还恢复 Prefab 局部 Transform。不要用 OnDisable 自动归还。禁用 Host 不释放池，退出关卡显式 Shutdown，OnDestroy 兜底。Prefab 由外部持有，池关闭不卸载资源。

## 失败与排错

初始化前借出、关闭后借出均报错。重置失败会淘汰对象；释放也失败时汇总两种错误。对象被外部销毁时，Host 跳过失效缓存。所有接入操作在主线程进行。资源准备、定时归还和业务回调取消由使用者负责。
