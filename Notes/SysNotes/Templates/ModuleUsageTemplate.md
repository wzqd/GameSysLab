# 模块使用指南

## 适用范围与入口

从角色受伤、界面打开或关卡退出等具体游戏需求开始，解释谁做什么；列出需要的模块方法和程序集依赖。保存到 Guides/<模块>/，不依赖演示类型。

## 最小使用流程

按游戏启动 / 进入关卡 → 角色或界面开始使用 → 发生游戏行为 → 界面关闭 / 离开关卡组织；提供准确代码，标明示例自定义类型和所在上下文。

## Unity 安装与调参

写具体场景路径、对象层级、挂载脚本、拖拽引用、参数默认值与单位、生效时间、启停行为；不适用时明确说明。描述构建入口要求，不将 Editor 结果当成 Player 验证。

## 所有权、失败与排错

写退出和场景切换时由谁清理；明确线程、重入、队列满、取消、错误报告与重试语义。指出返回成功是否只代表接收请求。

## 验证与限制

链接实验笔记、测试入口；区分已实现、已验证、计划和未覆盖条件。修改 API 时同步检查本页示例及索引。
